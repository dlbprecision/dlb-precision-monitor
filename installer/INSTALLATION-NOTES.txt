DLB Precision Monitor 0.1.4 - unsigned pilot build

For Windows 11 x64 PCs. This is a prerelease for testing, with broader hardware
and installation testing still in progress.

One setup installs the monitor and its DLB Precision Sensors service. Windows
administrator approval is required. Normal monitor launches do not need elevation.
The service reads sensors only while the monitor requests them.

Setup includes the unmodified, signed official PawnIO 2.2.0 hardware-access
installer. It reuses an accessible existing driver and first tries to start a
stopped driver. If the driver remains unavailable or is missing, setup runs the
bundled official installer. A detected newer version is preserved instead of
being replaced by the older bundle. Setup does not automatically uninstall PawnIO.

If setup requests a Windows restart, follow its instructions. You may need to
run this same DLB installer again after restarting to finish installation.
No separate driver download is needed. If setup still cannot finish, send DLB
the setup log. Sensors unsupported by the hardware or driver show as unavailable.

Uninstall removes DLB's installed files and DLB Precision Sensors service. PawnIO
is a shared dependency and remains installed because other applications may use
it. When no other applications need it, PawnIO can be removed separately from
Windows Settings > Apps > Installed apps.

Open setup normally (double-click) to configure startup for the original user.
For deployments launched from an already elevated terminal or another account,
launch the monitor from the target user's Start menu and configure startup there.
User display preferences are preserved on uninstall for a future reinstall.

The monitor is designed to stay on another display while you play. It does not
inject an overlay into games. Verify your games during the pilot.

Third-party notices, exact package versions, source locations and hashes are in
the installed licenses and provenance directories. This DLB installer and its
DLB application binaries are not publisher-signed. Windows may show an unknown
publisher or unrecognized-app warning for this unsigned build. The PawnIO payload
retains its original valid signature.
