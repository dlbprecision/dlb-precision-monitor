# DLB Precision Monitor v0.1.3 — pilot

This update fixes sensor diagnostics being cut off at the bottom of Settings.
Long details now wrap to their full height within the scrolling content area,
keeping the information readable and the existing footer controls accessible.
The Widget size slider and horizontal/vertical layouts remain available.

Download `DLB-Precision-Monitor-0.1.3-Setup.exe` from Assets, double-click it, and
follow setup. The `.sha256` file is an optional checksum. Check for
**DLB Precision, LLC** on the administrator prompt. One
installer includes the monitor, sensor service and PawnIO when needed.

The exact four diagnostic lines from the reported screenshot now display fully.
Long wrapped warnings remain reachable by scrolling, with Apply and Close fixed
in place. The build passed with zero warnings/errors. The signed upgrade from
v0.1.2 completed without a reboot and preserved user preferences. All 40 installed
widget checks and 22 live-service checks passed; installed signatures, timestamps
and runtime hashes were verified.

This remains a Windows 11 x64 pilot. Signing does not guarantee immediate
SmartScreen trust. Broader clean-PC, reboot/uninstall, hardware and game testing
remain pending; see the [validation notes](https://github.com/dlbprecision/dlb-precision-monitor/blob/v0.1.3/docs/VALIDATION.md).
