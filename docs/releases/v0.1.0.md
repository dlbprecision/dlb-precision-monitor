# DLB Precision Monitor v0.1.0 — pilot

A compact Windows 11 x64 hardware widget for a second monitor while gaming.

## Download

**[Download the Windows 11 installer](https://github.com/dlbprecision/dlb-precision-monitor/releases/download/v0.1.0/DLB-Precision-Monitor-0.1.0-Setup.exe)**

No GitHub account is needed. Download only the setup EXE; the `.sha256` asset is an optional checksum, not another installer.

1. Download setup using the link above. If your browser says it **isn't commonly downloaded**, open its Downloads list and choose **Keep** / **Keep anyway**, if offered, for this DLB download.
2. Double-click setup. If Windows says **Windows protected your PC** and describes an **unrecognized app**, choose **More info**, then **Run anyway**, only if you trust this official DLB pilot download.
3. Choose **Yes** on the Windows administrator prompt, then follow setup. The single installer includes the widget, sensor service, and signed PawnIO setup when needed; no separate hardware-monitoring program is required.

These instructions apply to reputation warnings. If Windows names a virus or threat, or provides no **Run anyway** option, stop and send DLB the exact message. Keep Windows Security enabled.

The DLB installer and app are unsigned pilot builds; **Unknown publisher** is expected on the administrator prompt. DLB publisher verification is in progress. The bundled PawnIO installer retains its original signature. Customer distribution awaits DLB signing and broader validation. [Microsoft explains these reputation warnings](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Included

- CPU temperature, load percentage, and clock in MHz.
- GPU temperature, load percentage, and core clock in MHz, with GPU selection.
- Physical RAM used in GB.
- One Celsius/Fahrenheit toggle for both temperatures.
- Resizable horizontal/vertical layouts, DLB blue/purple accents, adjustable opacity, and optional subtle branding.
- Position/size lock, launch at Windows sign-in, and a programmable show/hide shortcut (default Ctrl+Alt+F10).
- One-second or two-second refresh; hiding the widget stops its sensor polling.

## Validation and limits

Release builds passed, with 15 sensor-selection assertions, 25 widget assertions, and 22 codec/client/installed-service assertions. Live readings and normal-user startup configuration were verified on a Ryzen 9 9950X3D / NVIDIA RTX 5090 Windows 11 PC with PawnIO already installed.

The final installer includes a Settings Close-button fix and resource-disposal improvements. Reinstallation/upgrade of this final package and a fresh two-second performance run remain pending. Clean installation without existing PawnIO, reboot/upgrade/uninstall, additional CPU/GPU families, mixed-DPI displays, sleep/resume, and actual iRacing/ACC/COD sessions still need pilot testing.

The widget runs on another display. Same-screen exclusive-fullscreen game overlays are outside this release's scope. See [validation details](https://github.com/dlbprecision/dlb-precision-monitor/blob/v0.1.0/docs/VALIDATION.md) for measurement methods and remaining checks.
