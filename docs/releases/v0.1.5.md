# DLB Precision Monitor v0.1.5

The CPU Temp, CPU Load, CPU Clock, GPU Temp, GPU Load, GPU Clock and RAM Load
labels now use a brighter neutral white. The small optional DLB Precision
branding uses the same white. Font sizes, layout, transparency and DLB's blue
and purple colors stay the same.

To update, download **DLB-Precision-Monitor-0.1.5-Setup.exe**, right-click the
monitor and choose **Exit**, then run setup. You do not need to uninstall first;
your saved settings are retained. Reopen the monitor from its desktop shortcut.
This single installer includes the application, sensor service, libraries and
official signed PawnIO setup, with the installation improvements from v0.1.4.
The `.sha256` file is an optional checksum, not another installer.

Setup and DLB's application files are signed and timestamped as **DLB Precision,
LLC**. The existing automated checks passed, and the brighter labels and branding
were visually checked in both orientations, at minimum size and at 150% DPI.
The office PC upgraded successfully without a restart.

This remains a pilot release. See the [validation record](https://github.com/dlbprecision/dlb-precision-monitor/blob/main/docs/VALIDATION.md)
for completed checks and outstanding hardware and installation coverage.
