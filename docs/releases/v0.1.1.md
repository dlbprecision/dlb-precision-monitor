# DLB Precision Monitor v0.1.1 — pilot

A compact Windows 11 x64 hardware widget for a second monitor while gaming. This
is the first publisher-signed pilot and remains a prerelease for testing.

## Download

Download `DLB-Precision-Monitor-0.1.1-Setup.exe` from this release's Assets. The
`.sha256` asset is an optional checksum, not another installer. No GitHub account
is needed for the public download.

Double-click setup, check the publisher is **DLB Precision, LLC** on the Windows
administrator prompt, then follow the installer. One installer includes the
widget, its sensor service and the original signed PawnIO installer when needed.
No separate hardware-monitoring application is required. Existing PawnIO
installations are preserved.

A new download can still trigger browser or Windows SmartScreen reputation
warnings despite a valid publisher signature. Signing identifies the publisher;
it does not guarantee immediate SmartScreen trust. Keep Windows Security enabled.
If Windows names a virus or threat, send DLB the exact message before proceeding.
[Microsoft explains SmartScreen reputation](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Changes in this release

- DLB Precision, LLC signatures and timestamps on setup, the uninstaller, the
  monitor and sensor-service executables, and DLB's Shared and Sensors libraries.
  Bundled third-party files retain their original bytes and vendor signatures.
- A desktop shortcut selected by default on fresh installations.
- The Settings **Close** button fix included in the installed application.
- Installation notes that describe the signed pilot and its remaining limits.

CPU and GPU temperature, load and clock readings, RAM used in GB, the shared
Celsius/Fahrenheit toggle, resizable horizontal/vertical layouts, adjustable
opacity, subtle optional branding, position lock, startup and a programmable
show/hide shortcut remain included.

## Validation and limits

The September 8 signed build and its embedded uninstaller passed signature
verification with zero warnings/errors. After upgrading the test PC, all four
installed DLB application files (version 0.1.1.0) and `unins000.exe` passed
SignTool and Authenticode checks for valid signatures, the exact publisher
**DLB Precision, LLC**, and timestamps. All 19 installed runtime hashes matched;
first-party files matched the signed staging files, and the PawnIO payload
retained its original pinned hash.

The upgrade from the local unsigned v0.1.0 build containing the Settings Close
fix to signed v0.1.1 completed with exit code 0 and no restart required. It used
silent setup launched from a non-elevated parent on the Ryzen 9 9950X3D /
RTX 5090 Windows 11 PC with PawnIO already installed. The sensor service was
running with Automatic startup. All 22 codec/client and installed-service
integration assertions passed, with all seven readings available and no sensor
warnings. All 25 installed-widget assertions passed, including actual modeless
Settings Close behavior. Source builds and their 18 codec/client, 15 sensor and
25 widget assertions also passed with zero build warnings/errors.

The existing desktop shortcut launched the responding signed v0.1.1 app after
upgrade. User settings and the existing startup command were preserved, and the
signed-pilot installation notes were installed. The fresh-install desktop
shortcut default is confirmed in source; this upgrade preserved the previous
task selection.

Setup is 7,429,968 bytes. SHA256:

```text
5dc174d7af619dd4fc6ee45ae610916d6112f067bd617d57244008a4188b986a
```

Clean-PC installation without existing PawnIO, reboot/startup and uninstall
coverage, ordinary double-click setup/startup, additional Intel/AMD CPU and GPU
families, mixed-DPI displays, sleep/resume and actual iRacing/ACC/COD sessions
still need pilot testing. This upgrade does not establish those behaviors.
See [validation details](https://github.com/dlbprecision/dlb-precision-monitor/blob/v0.1.1/docs/VALIDATION.md)
for the historical performance measurements and remaining checks.

The earlier v0.1.0 release remains available as an unsigned historical pilot;
its original assets and checksum are unchanged.

The widget stays on another display while games run. Same-screen exclusive-
fullscreen game overlays are outside this release's scope. PawnIO is a shared
dependency and remains installed when DLB Precision Monitor is uninstalled.
