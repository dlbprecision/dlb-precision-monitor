# DLB Precision Monitor v0.1.7

Removes the box that briefly appeared around the widget after clicking another
window, and makes the **Every second** refresh actually update every second.
Previously the readings changed only every 2 seconds on either refresh setting.

The **Widget size** slider in Settings now goes from 50% to 150% (it was 75% to
200%), and the whole widget scales evenly, including its borders and footer.

The widget no longer takes keyboard focus when it opens at sign-in, when the
show / hide shortcut brings it back, or when the app is opened again, so the
shortcut cannot pull a game out of focus. Opening the app while the widget is
already running leaves it where you placed it; **Move to primary monitor** in
the right-click menu still brings it to the main display.

Also in this release:

- A shortcut used by another app no longer stops your other settings from
  saving.
- Changing layout or locking from the right-click menu while Settings is open is
  no longer undone by **Apply**.
- GPU readings that disappear (for example after a graphics-driver update) are
  retried automatically, as CPU readings already were.
- An unexpected error is recorded in
  `%LOCALAPPDATA%\DLBPrecision\Monitor\error.log` instead of showing an error
  box, and the widget keeps running.

To update, download **DLB-Precision-Monitor-0.1.7-Setup.exe**, right-click the
monitor and choose **Exit**, then run setup. No uninstall is needed; your saved
settings, size and position are retained. Reopen the monitor from its desktop
shortcut.

The single installer includes the application, sensor service, libraries and
official signed PawnIO setup. The `.sha256` file is an optional checksum, not
another installer. Setup and DLB's application files are signed and timestamped
as **DLB Precision, LLC**.

With true 1-second updates the sensor service uses about 1.3–1.6% of one CPU
thread on the office PC (about 0.05% of its 32-thread processor). Choose
**Every 2 seconds** in Settings for the lighter rate.

The office PC upgraded from v0.1.6 with its settings, position and shared driver
preserved, and the installed build passed the full regression suite with live
readings. This remains a pilot release. See the [validation record](https://github.com/dlbprecision/dlb-precision-monitor/blob/main/docs/VALIDATION.md)
for completed checks and remaining hardware coverage.
