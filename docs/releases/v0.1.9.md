Makes **Check for updates** ready for everyone. This is the first version offered through the monitor's own Check for updates. Your settings, size, position and launch-at-sign-in choice are kept. If Windows asks for permission, choose **Yes**.

- The update window now opens in front of Settings. Before, with "Keep above desktop windows" on, it could open hidden behind the Settings window.
- The update window and Settings now fit their text at every Windows display scaling, including 125%, 150% and 200%.
- Clearer results: if setup can't start, the window shows setup's own reason; if the sensor service doesn't start after an update, it says to restart Windows; it only says the monitor reopened when it did; and if another Windows user on the PC has the monitor open, it asks you to close it there first.
- Pressing Enter a second time after **Update now** no longer cancels the download.
- Stricter download checks: an update must be signed by DLB Precision, LLC of Arkansas, US, and must be the DLB Precision Monitor setup itself.
- Hovering over the widget shows its sensor details again, even while a game or another app has focus.
- A graphics card that is unplugged or disabled no longer leaves a permanent sensor warning, and it no longer stops the CPU sensors from recovering later.
- When GitHub limits update checks from your network, the message says when to try again.

This is a pilot release; broader hardware testing is still in progress. For a new installation, or to update from v0.1.7 or earlier, follow the download steps in the README: https://github.com/dlbprecision/dlb-precision-monitor#install
