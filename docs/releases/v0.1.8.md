# DLB Precision Monitor v0.1.8

Adds **Check for updates**, so later versions install from inside the monitor
instead of from this page.

Right-click the monitor, or open **Settings**, and choose **Check for updates…**.
If a newer version is available, its notes are shown; choose **Update now**. The
monitor downloads it, confirms it is genuinely signed by **DLB Precision, LLC**,
and installs it. If Windows asks for permission, choose **Yes**. The monitor
closes and reopens on the new version with its settings, size, position and
launch-at-sign-in choice kept.

The monitor checks only when you ask. Nothing runs in the background, and the
widget's own CPU and memory use is unchanged: the check, download and install
happen in a separate, short-lived updater that exists only while it works.

**This is the last manual update.** Download
**DLB-Precision-Monitor-0.1.8-Setup.exe**, right-click the monitor and choose
**Exit**, then run setup. No uninstall is needed; your saved settings are kept.
Reopen the monitor from its desktop shortcut. From 0.1.8 on, use Check for
updates.

v0.1.8 keeps every v0.1.7 fix: no flashing box after clicking another window,
true 1-second refresh, the 50–150% size slider, and the shortcut never taking
focus from a game.

The single installer includes the application, updater, sensor service,
libraries and official signed PawnIO setup. The `.sha256` file is an optional
checksum, not another installer. Setup and DLB's application files are signed
and timestamped as **DLB Precision, LLC**.

This remains a pilot release. See the [validation record](https://github.com/dlbprecision/dlb-precision-monitor/blob/main/docs/VALIDATION.md)
for completed checks and remaining hardware coverage.
