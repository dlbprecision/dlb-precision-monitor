# DLB Precision Monitor v0.1.4

This update fixes setup stopping with **"An incomplete PawnIO installation was
found."** Everything DLB supplies is included in one installer: the widget,
sensor service, application libraries and the official signed PawnIO installer.
Windows 11 supplies the .NET Framework runtime.

Download **DLB-Precision-Monitor-0.1.4-Setup.exe**. The `.sha256` file is an
optional checksum, not another program to install. Existing users can run setup
to upgrade; display preferences are retained.

## What changed

- Setup checks whether the real PawnIO driver is running and accessible. A
  missing, unused `PawnIOLib.dll` no longer incorrectly blocks installation.
- An existing stopped driver is started before attempting reinstallation.
- If the driver is absent or still unavailable, DLB runs the bundled official
  installer using its supported installation command and checks the result.
- If Windows needs a restart before the driver is available, setup explains how
  to finish using this same DLB installer. No separate driver download is needed.
- Working shared drivers are preserved; detected newer unavailable versions are not
  automatically downgraded, and DLB never automatically uninstalls PawnIO.

Setup and DLB's application files are signed and timestamped as **DLB Precision,
LLC**. PawnIO retains its original publisher signature. New downloads may still
receive Windows reputation warnings.

This remains a pilot release. The prerequisite decision paths have a compiled,
non-destructive test harness. That does not substitute for installing on the
affected sim PC or testing real driver repair on a disposable Windows system.
See [validation status](https://github.com/dlbprecision/dlb-precision-monitor/blob/main/docs/VALIDATION.md)
for the completed checks and remaining coverage.
