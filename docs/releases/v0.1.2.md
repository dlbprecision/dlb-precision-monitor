# DLB Precision Monitor v0.1.2 — pilot

A Windows 11 x64 hardware widget for a second monitor while gaming. This pilot
adds a Widget size slider and repairs edge/corner resizing. It is signed under
DLB Precision, LLC and remains a prerelease for testing.

## Download

Download `DLB-Precision-Monitor-0.1.2-Setup.exe` from this release's Assets. The
`.sha256` file is an optional checksum, not a second installer. No GitHub account
is needed.

Double-click setup, check for **DLB Precision, LLC** on the Windows administrator
prompt, then follow setup. One installer contains the widget, sensor service and
the original signed PawnIO installer when needed. Existing PawnIO installations
are preserved. A publisher signature identifies DLB; a new download can still
show browser or SmartScreen reputation warnings.

## Resize the monitor

Right-click the widget and open **Settings**. Move **Widget size** between **75% and
200%**, then click **Apply**. This works for both horizontal and vertical layouts,
and the resulting dimensions are saved. The size fits your current display.

For a custom shape, unlock position/size and drag any edge or corner. Applying
unrelated settings preserves the custom dimensions unless a size or layout
change is requested. A resize grip is visible while unlocked. Position/size
locking prevents dragging and edge/corner resizing.

## Changes in this release

- A **Widget size** slider in Settings with an Apply action.
- Repaired native edge/corner resizing for the borderless widget.
- Saved dimensions and preservation of custom geometry when applying unrelated
  settings.
- Settings content scrolls vertically when needed, keeping the Close button
  accessible without horizontal overflow.
- Continued DLB Precision, LLC signing and timestamping for first-party files,
  setup and the uninstaller, with original third-party files preserved.

The existing readings, Celsius/Fahrenheit toggle, opacity, branding, launch at
sign-in and programmable show/hide shortcut remain included. The previous
Settings Close fix and fresh-install desktop shortcut default are retained.

## Validation and limits

The September 8 build completed with zero warnings/errors. Setup, the embedded
uninstaller and all four first-party DLB files passed signature and timestamp
verification. After upgrade, the four installed DLB files (version 0.1.2.0) and
`unins000.exe` had valid signatures, the exact publisher **DLB Precision, LLC**,
and timestamps. All 19 installed runtime hashes matched the staged files and
manifest. The builder verified the unchanged pinned PawnIO payload.

The upgrade from signed v0.1.1 used silent setup launched from a non-elevated
parent and finished with exit code 0, without a reboot. The sensor service was
running with Automatic startup. User settings and the existing startup command
were unchanged, and the desktop shortcut launched the installed v0.1.2 monitor.

All 40 installed-widget assertions passed, covering compact and enlarged sizing,
both orientations, DPI scaling calculations, compact-layout round trips, actual Settings
slider callbacks and repeated Apply behavior, preservation of size when applying
unrelated settings, saved dimensions, and scrolling with an accessible Close
button. All 22 live client/integration assertions passed, with all seven readings
available and no warnings on the Ryzen 9 9950X3D / RTX 5090 test PC. Prebuild
checks passed 18 client and 15 sensor assertions.

Horizontal and vertical renders at 75%, default and large sizes were readable.
An isolated 490-by-450 Settings window check verified its fixed footer and
vertical scrolling without horizontal overflow. Physical high-DPI behavior and
actual mouse edge/corner dragging have not been manually tested; native resizing
style and hit-test handling were reviewed in code.
