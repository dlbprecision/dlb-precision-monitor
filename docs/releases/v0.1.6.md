# DLB Precision Monitor v0.1.6

Fixes CPU temperature and CPU clock staying as dashes after starting Windows
when the sensor driver has not started. Previously, reinstalling DLB could
temporarily restore those readings because setup started the driver.

DLB now starts the installed sensor driver when needed before opening sensors.
It also makes a few spaced-out recovery attempts if the CPU readings remain
unavailable. Healthy readings reuse the existing connection, and monitoring
remains idle when the widget is hidden or closed.

To update, download **DLB-Precision-Monitor-0.1.6-Setup.exe**, right-click the
monitor and choose **Exit**, then run setup. No uninstall is needed; your saved
settings are retained. Reopen the monitor from its desktop shortcut. On a PC
affected by the startup issue, check the readings after the next Windows restart.

The single installer includes the application, sensor service, libraries and
official signed PawnIO setup. The `.sha256` file is an optional checksum, not
another installer. Setup and DLB's application files are signed and timestamped
as **DLB Precision, LLC**.

The regression suite passed, including 19 new driver-startup and recovery checks.
The office PC upgraded successfully and returned all seven live readings. The
affected rig still needs a post-update restart to verify its original boot issue.

This remains a pilot release. See the [validation record](https://github.com/dlbprecision/dlb-precision-monitor/blob/main/docs/VALIDATION.md)
for completed checks and remaining hardware and reboot coverage.
